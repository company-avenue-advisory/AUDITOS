# AuditOS Frontend: Next.js Tax Audit Workspace

This is the Next.js frontend workspace for AuditOS, an enterprise CA-level invoice auditor. It features a side-by-side verification interface and a productivity-optimized Full-Screen grid workspace for checking and editing extracted tax columns.

## Getting Started

1. Ensure the parent directory's backend is running on port `8080` (or the port defined in `.env.local`'s `NEXT_PUBLIC_API_URL`).
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev -- -p 3001
   ```
4. Open [http://localhost:3001](http://localhost:3001) in your browser.

Refer to the root [README.md](../README.md) for the complete architecture, features, and setup instructions.
